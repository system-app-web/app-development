# アセスメントシート

`app.html` を使う単一HTMLのアプリです。Vercelの設定は、このファイルを `dist/index.html` にコピーして公開します。

## 使い方

1. 作成ページに、アセスメント用プロンプトの217項目を順番に貼り付けます。
2. 「シートを作成」を押し、各シートの内容を確認します。「記載なし」は空欄になります。
3. 必要に応じて入力・書式を調整し、PDF保存・印刷ができます。

「PDF保存・印刷」では、印刷するシートを選択できます。「Excel保存」は、No.1〜3・入院・退院・フェイスシートを分けたマクロなしのExcelファイルを、端末内で作成します。

フェイスシートはほかのシートと共通の項目を共有します。氏名や保険情報などは、どちらのシートで変更しても同じ記録に保存されます。フェイスシートも印刷・PDFとExcelに含められます。

## 資料からAIで作成するための設定

1. Google AI Studioで、Gemini APIを利用するGoogle CloudプロジェクトとAPIキーを用意します。**キーは他人に送らず、画面にも入力しません。**
2. 利用するプロジェクトの課金状態、Googleのデータ取扱条件、利用者の同意を確認します。Googleは無料枠に機密情報・個人情報を送らないよう求めています。実際の個人情報を送る前に、事業所のルールも確認してください。APIの使用には料金が発生します。
3. Vercelのアセスメントシートのプロジェクトを開き、「Settings」→「Environment Variables」を開きます。
4. 名前に `GEMINI_API_KEY`、値にGoogleで発行したキーを入力します。使う環境（Preview／Production）を選んで保存します。キーそのものは共有しないでください。
5. 同じ画面で、名前を `ASSESSMENT_PROMPT` とする環境変数も追加し、`prompt_アセスメント_通常.txt` の全文を値に貼り付けて保存します。プロンプトは公開リポジトリには含めていません。
6. 環境変数は新しいデプロイから有効です。まずPreviewで架空の資料だけを使って確認してください。本番への反映は別途、公開の指示が必要です。

作成ページで資料を1つ以上選んで作成します。PDF・PNG・JPEG・WebP・GIFに対応し、合計3MB以内です。資料は一時的にサーバーを通ってGeminiに送信されますが、このアプリは資料ファイルを保存しません。Google側の保存や取扱いはGoogleの規約が適用されます。生成結果には誤りがあり得るため、必ず人が確認してください。AI接続はポータルで承認された端末のみが利用できます。1回の生成で既存の217項目を上書きするため、実行前に確認画面を表示します。

詳細は [GoogleのAPIキーの案内](https://ai.google.dev/gemini-api/docs/api-key)、[Googleの利用規約](https://ai.google.dev/gemini-api/terms)、[Vercelの環境変数の案内](https://vercel.com/docs/environment-variables) を参照してください。

左のメニューから「かんたんジェノグラム」「シンプル見取り図」を開き、図を作成して「アセスメントシートへ貼り付け」を押すと、選択中の記録に図が入ります。図の欄を選択して Ctrl+V（MacはCommand+V）を押すと、別の画像を貼り付けることもできます。図を貼り付けると、その時点の編集内容も記録のバックアップに含まれます。

## 保存

記録はブラウザのlocalStorageに保存され、IndexedDBに日次バックアップを作成します。「バックアップ」からJSONファイルに保存し、「データ挿入」から復元できます。ブラウザのデータを消す前や別の端末に移す前にはJSONバックアップを作成してください。

## Googleドライブへのバックアップ設定

この機能を使う場合は、次の準備が必要です。個人と会社はそれぞれのGoogleアカウントの「マイドライブ」を使用します。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成または選択します。
2. 「APIとサービス」のライブラリで「Google Drive API」を有効にします。
3. 「Google Auth Platform」の同意画面を設定します。個人アカウントで試す場合は対象を「外部」にし、「テストユーザー」に自分のGoogleアカウントを追加します。必要な権限は `https://www.googleapis.com/auth/drive.file` です。
4. 「クライアント」で「ウェブアプリケーション」のOAuthクライアントを作成し、「承認済みのJavaScript生成元」にアプリを開くHTTPSのURLのドメイン部分を登録します（例：`https://example.com`。末尾のパスは含めません）。
5. 作成された「クライアントID」をアプリの「ドライブ保存」に入力し、保存先を選んで「Googleに接続」を押します。表示されたメールアドレスが正しいことを確認して許可します。クライアントシークレットは入力・共有しません。
6. 接続中は編集後にJSONバックアップを自動追加します。ブラウザを閉じた後や接続期限が切れたときは、再度「Googleに接続」が必要です。画面に表示される保存状況を確認してから閉じてください。

以前のバックアップは上書きせずに追加します。ドライブの記録が新しい可能性があるときは自動保存を停止します。「最新のバックアップを取得」でJSONをダウンロードして中身を確認し、必要なら「データ挿入」から復元できます。復元は端末内の全記録を置き換えるため、先に現在のバックアップを保存してください。時刻による新旧判定は端末の時計のずれで正確でない場合があります。

OAuthクライアントの詳細は [Google公式の手順](https://developers.google.com/workspace/guides/create-credentials) と [同意画面の設定](https://developers.google.com/workspace/guides/configure-oauth-consent) を参照してください。

## 確認

`npm test` でHTML内のJavaScriptを検査します。ブラウザでの合成データによる結合テストは、`ASSESSMENT_PLAYWRIGHT` にPlaywrightの `index.mjs`、`ASSESSMENT_BROWSER` にChromium系ブラウザの実行ファイルを指定すると実行されます。テストでは実在する利用者データを使いません。
