# アセスメントシート

端末内で利用者ごとのアセスメントを作成・保管するWebアプリです。現在の版では、データをサーバーへ送信せず、ブラウザ内に保存します。

## 主な機能

- 利用者・アセスメント履歴の一覧
- 新規作成と複製
- Google AI Studioの159項目出力を貼り付けて自動転記
- 空欄・「記載なし」・「詳細不明」を黄色で要確認表示
- アプリ内履歴への自動保存
- JSONファイルへの保存と読み込み
- PDF保存・印刷
- エクセルシート、入院時連携、退院時連携、フェイスシートの切り替え

## ローカルで起動する方法

```bash
pnpm dev
```

表示されたローカルURLをブラウザで開きます。
