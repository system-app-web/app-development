# デスクトップメモ

Windowsでは小さな付箋のように置いて使い、スマートフォンやタブレットでは一覧からメモを選ぶアプリです。画面はReact + TypeScriptで共通にしています。デスクトップ版は軽量なTauri 2で動きます。

## Windowsで開発用に起動する

Windows 10または11で、次の準備をします。

- Node.js 22.12以上
- Rustの安定版
- Visual Studio Build ToolsのC++ツール
- WebView2 Runtime（通常はWindowsに入っています）
- pnpm

このフォルダをPowerShellで開き、次を実行します。

    pnpm install
    pnpm tauri dev

## Windows用インストーラーを作る

アプリのフォルダで次を実行します。

    pnpm install
    pnpm tauri build

作成されたNSISインストーラーは、次の場所に出力されます。

    src-tauri/target/release/bundle/nsis/

この方法で作る場合はWindows上で実行してください。自分のMacやWindows PCを使わずに作る場合は、次のGitHub Actionsを使えます。

## GitHub ActionsでWindowsインストーラーを作る

GitHub Actionsは、GitHub上で作業を自動実行する機能です。この設定では、`main`（GitHub上の基本の保存先）に変更を送ると、GitHub上のWindows環境でインストーラーを自動作成します。GitHub画面のボタンから手動で作成することもできます。作成したインストーラーは30日間ダウンロードできます。

### GitHub画面から手動で作る

1. GitHubでこのリポジトリを開き、上の「Actions」をクリックします。
2. 左側の「Windows installer」をクリックします。
3. 「Run workflow」をクリックし、表示された選択欄で`main`を選んで、もう一度「Run workflow」をクリックします。
4. 実行一覧に出た新しい行をクリックします。緑色のチェックが付けば作成完了です。
5. 実行結果ページ下部の「Artifacts」（作成されたファイル）にある`desktop-memo-windows-installer`をクリックします。
6. ダウンロードしたZIP（圧縮ファイル）を展開すると、Windows用インストーラー（`.exe`）が入っています。

### Windowsの警告が出た場合

このインストーラーにはコード署名がありません。そのため、Windowsに「発行元不明」や「WindowsによってPCが保護されました」と表示されることがあります。

1. GitHubのこのリポジトリからダウンロードしたファイルであることを確認します。
2. 警告に「詳細情報」が表示された場合はクリックします。
3. 入手元を確認でき、インストールしてよいファイルだと確認できた場合のみ「実行」をクリックします。
4. 「実行」が表示されない場合や、会社のPCでブロックされた場合は、保護機能を無効にせず、社内の管理担当者に相談してください。

この成果物をダウンロードするには、GitHubでこのリポジトリを閲覧できる必要があります。

## 基本の使い方

- メモ本文は入力すると自動保存されます。
- 左側の短い色付き付箋を選ぶと本文が開きます。「＋」から追加し、本文の「⋯」から名前、色、並び順、削除、バックアップ、データ挿入を操作できます。
- ウィンドウ上部をダブルクリックすると配置調整モードになります。上部をドラッグして移動し、枠の端をドラッグしてサイズを変えます。もう一度ダブルクリックするか、別の場所をクリックすると固定されます。
- 位置と大きさは保存されます。モニターが変わって保存した位置が画面外になった場合は、表示中の画面に戻します。
- 通知領域のアイコンをクリックすると表示・非表示を切り替えます。右クリックのメニューから表示、非表示、終了を選べます。
- Windowsでアプリを最初に起動したとき、自動起動を登録します。

## 保存とバックアップ

メモは通常保存に加えてIndexedDBにも自動バックアップされます。同じ日付のバックアップは最新状態に更新し、30日分を保管します。通常保存が読み取れない場合は新しいバックアップから復元します。

「バックアップ」はJSONファイルを書き出します。「データ挿入」はこのアプリ用のJSONだけを受け付け、置き換える前に確認します。

PC版とWeb版の保存先は、同期機能を設定するまで別々です。同期先を選んだ後に、同じメモを複数端末で共有できるようにします。
