# 提供票 自動振り分け

サービス提供票PDFを、事業所ごとのPDFへまとめるためのブラウザ完結型Webアプリです。

現在は実提供票（SVF形式・令和8年10月）に合わせ、次を優先して判定します。

- 被保険者氏名から利用者名を取得
- 別表の「事業所番号」列より後にある10桁番号を事業所の主キーとして取得
- 名称が似ていても事業所番号が異なる書類は結合しない
- 「居宅療養管理指導」を含む書類は、送付方法にかかわらず`居宅療養`へ分類
- 2ページ固定ではなく、利用者名・事業所名の変化とページ順で束ねる（実サンプルの3ページ構成にも対応）

`事業所マスタ`には、10桁の事業所番号ごとにLINE／FAX／メール／手渡し／その他を登録します。未設定のものは要確認扱いとなり、出力を止めます。

設定と事業所マスタは通常のブラウザ保存に加え、`service-slip-sorter-backups`というIndexedDBへ日次自動バックアップされます。PDF本体・利用者名・処理結果はバックアップしません。直近30日分を保持します。

## 起動

```bash
pnpm install
pnpm dev
```

`npm` を使う場合は `npm install` / `npm run dev` でも起動できます。

## 個人情報の扱い

- PDF読み込み・文字抽出（PDF.js）・ページ結合（pdf-lib）・ZIP作成（JSZip）はブラウザ内だけで実行します。
- Gemini補助判定は常時有効ですが、ローカル解析で事業所名・番号を判定できず、事業所関連の文字情報がある場合だけ自動でAPIを呼び出します。事業所名・番号に問題がない要確認（マスタの送付方法のみ、重複のみ、提供年月のみ等）では呼び出しません。
- APIキーはVercelのSecretからサーバー側で読み込みます。APIキーをブラウザやソースコードへ入れてはいけません。

## Gemini補助判定（要確認時のみ自動）

`api/gemini-assist.ts` はVercelサーバー側でだけ実行されます。`GEMINI_API_KEY`をSecretとして読み、PDFそのものではなく、ローカルで抽出した事業所関連行（最大1,600文字）と事業所名・番号をGeminiへ送ります。高い確信度で既存マスタの事業所番号と照合できた場合だけ、事業所情報の判定を自動補完します。新しい番号は送付方法未設定のマスタ行として追加し、送付方法が決まるまで保存を止めます。マスタとの照合ができない候補は要確認のままにします。Geminiに送付方法を決めさせたり、ダウンロードを自動実行したりはしません。

Gemini補助判定を実行する際は、スタッフポータルの既存端末ログインをサーバー側で確認します。スタッフは別の合言葉を入力しません。認証結果はポータルの利用履歴にも記録します。

## 実PDFに合わせた解析調整

PDF形式ごとの差異は `src/analysis-rules.ts` に集約しています。実際のケアマネソフトの提供票を確認後、利用者名・事業所名のラベル、提供年月の正規表現、座標に基づく判定をこのファイルへ追加してください。

初期ルールは、利用者氏名・利用者名・被保険者氏名、サービス事業所名・提供事業所名等のラベルを対象にします。利用者または事業所が判定できないページは要確認として出力を止めます。
